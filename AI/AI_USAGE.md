AI assistance was used throughout the development of this project to:

- Explain SQLite database design.
- Generate initial code examples.
- Assist in writing automated tests.
- Assist in preparing project documentation.

## Author contribution

The application was built incrementally. AI suggestions were used as guidance and were adapted where necessary to satisfy the assignment requirements.
